# SQL Crime Data Analysis

## Project Overview
This beginner SQL project analyzes a crime dataset using basic SQL queries. The goal of this project is to practice SQL fundamentals such as selecting data, filtering records, grouping results, sorting data, and using aggregate functions.

## Dataset
The dataset used for this project is a crime dataset containing details such as crime type, area name, victim age, victim gender, weapon description, premise description, and crime status.

## Key Insights

- Central and Southwest areas showed high crime activity.
- Certain crime types appeared significantly more frequently than others.
- Nighttime crime occurrences were common after 8 PM.
- Crimes involving weapons represented a notable portion of incidents.
- Single-family dwellings were among common crime locations.
- Victim demographics showed trends across age and gender categories.
